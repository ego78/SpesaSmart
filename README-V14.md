# Spesa Smart v14.0 — Dispensa intelligente

## Novità

- nuova sezione **Dispensa intelligente**;
- quantità disponibili e soglia minima per ogni prodotto;
- pulsanti rapidi `+` e `−` per registrare i consumi;
- data di scadenza, supermercato, prezzo pagato e note;
- avvisi per scorte basse, prodotti in scadenza entro 7 giorni e prodotti scaduti;
- trasferimento dei prodotti spuntati dalla modalità **Spesa in corso** alla dispensa;
- dopo il trasferimento, le spunte della lista vengono azzerate per evitare doppi inserimenti;
- dispensa inclusa nel backup JSON;
- dati salvati localmente senza rallentare il caricamento delle offerte.

## Utilizzo

1. Apri **Dispensa** dalla barra inferiore o dalla sezione in home.
2. Aggiungi manualmente una scorta oppure completa la spesa e premi **Aggiungi presi alla dispensa**.
3. Imposta una soglia minima per vedere l’avviso “Scorta bassa”.
4. Usa `+` e `−` per aggiornare rapidamente le quantità.
