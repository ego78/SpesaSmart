# Spesa Smart v15.0 – Acquisti e scontrini

Questa versione aggiunge un archivio locale degli acquisti con inserimento assistito dello scontrino.

## Funzioni

- foto dello scontrino come riferimento temporaneo durante l’inserimento;
- righe prodotto con quantità, unità e prezzo unitario;
- calcolo automatico del totale;
- archivio degli scontrini e riepilogo mensile;
- modifica ed eliminazione degli acquisti;
- trasferimento dei prodotti selezionati alla Dispensa;
- inclusione degli scontrini nel backup JSON.

La foto non viene salvata, per evitare di saturare lo spazio del browser. Il riconoscimento automatico OCR è previsto per una versione successiva.
