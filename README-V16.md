# Spesa Smart v16.0 — Smart Product Engine

- riconoscimento automatico delle righe OCR tramite catalogo, dispensa, acquisti e offerte;
- punteggio di affidabilità verde/giallo/rosso;
- selezione rapida dei candidati incerti;
- memoria personale degli alias dello scontrino;
- creazione automatica dei prodotti sconosciuti nel catalogo personale;
- collegamento `productId` tra scontrino e dispensa;
- nessun calcolo del motore durante la normale navigazione: il riconoscimento parte soltanto con l'OCR.
