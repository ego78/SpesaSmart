# Spesa Smart v12.0 — Storico prezzi

La v12 aggiunge uno storico giornaliero delle offerte senza appesantire l'avvio dell'app.

## Funzioni
- snapshot giornaliero creato da GitHub Actions durante la scansione;
- conservazione automatica degli ultimi 180 giorni;
- storico caricato soltanto quando l'utente apre il relativo popup;
- minimo, media, numero di rilevazioni e valutazione del prezzo corrente;
- etichette “Prezzo ottimo”, “Nella media” e “Più caro del solito”.

Lo storico parte vuoto: si popola dal primo aggiornamento delle offerte eseguito dopo la pubblicazione della v12.
