# Spesa Smart v18.0 – Assistente Smart locale

Questa versione aggiunge un assistente integrato che usa lista, dispensa, scontrini, budget, offerte e piani di acquisto.

## Funzioni
- analisi settimanale;
- situazione budget;
- scorte basse e prodotti in scadenza;
- riepilogo della lista;
- suggerimento della Spesa Perfetta;
- aggiunta automatica delle scorte basse alla lista.

Le elaborazioni principali avvengono localmente e non richiedono chiavi API. Il modulo è separato in `assets/js/assistant.js`, pronto per una futura integrazione cloud opzionale.
